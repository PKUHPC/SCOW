# 账户白名单

账户白名单用于特殊管理某些账户，使其免受欠费封锁规则的影响。

## 功能说明

当一个账户被加入白名单后：
1.  **免除封锁**：即使该账户余额不足（欠费），系统也不会将其封锁。
2.  **自动解封**：如果账户在加入白名单前因欠费已被封锁，加入白名单后会自动解封，恢复正常状态。
3.  **状态保护**：只要还在白名单有效期内，账户将始终保持正常状态（除非管理员手动封锁）。

## 有效期说明

在添加白名单时，管理员可以选择有效期（如一周、一个月、一年、永久或自定义日期）。

- **生效时间**：添加即刻生效。
- **过期时间**：
    - 系统会将过期时间设置为所选日期的 **00:00:00**。
    - 清理任务默认在每天凌晨 **00:00** 执行。
    - 如果当前时间超过了过期时间，系统会将该账户移出白名单。
    - **示例**：如果您设置有效期至 `2023-12-31`，系统通常将其记录为 `2024-01-01 00:00:00`。
        - 根据当前逻辑，如果截止时间是 `2024-01-01 00:00:00`，且清理任务在 `2024-01-01 00:00:00` 运行，只有当 `过期时间 < 当前时间` 时才会被清理。
        - 因此，该账户在 `2023-12-31` 当天仍然有效，通常会在 `2024-01-01` 凌晨的清理任务中被移出。

:::info
移出白名单后，系统会立即重新检查该账户的余额状态。如果账户仍处于欠费状态，将会被重新封锁。
:::
