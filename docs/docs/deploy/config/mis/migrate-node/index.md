# 节点迁移功能

节点迁移功能可细分为节点迁移和节点上线两个功能。

## 节点迁移

当同时满足以下情况时，管理系统允许平台管理员在SCOW中迁移节点到可选目标集群。

- 当前节点在当前集群中上线
- 当前节点在所有关联集群中下线
- 当前节点处于空闲状态

## 节点上线

当前节点在所有关联集群中下线时，管理系统允许平台管理员在SCOW中将节点上线到当前集群。

## 节点名匹配规则

为适配不同调度系统对主机名大小写处理不一致的情况，节点迁移功能在跨集群状态比对时采用大小写不敏感匹配。

- 例如 `WM-H800-02` 与 `wm-h800-02` 会被视为同一节点进行状态聚合与可操作性判断。
- 该规则仅用于节点状态比较，不会修改节点在各集群中的原始名称。
- 页面展示与迁移/上线接口传参仍使用当前集群返回的原始节点名。
- 迁移到目标集群时，系统会自动使用目标集群中的原始节点名执行上线操作。

# 节点迁移配置

要想开启关闭节点迁移功能，可以在配置文件中配置，默认不开启。

```yaml title="config/mis.yaml"
# 节点迁移功能
nodeMigration:

  # 是否开启节点迁移功能，默认为false
  enabled: false

  # 可以相互迁移的集群组, 组内各集群之间部分节点根据实际情况具有相互迁移可能性，如果enabled为true必须填写
  migratableClusterGroups:
    - group: ["linux", "ai01"]
    - group: ["linux", "ai02", "crane01"]
```

当您关闭此功能时，UI上所有关于节点迁移的功能的链接都会被隐藏。
