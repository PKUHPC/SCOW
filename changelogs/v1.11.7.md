# 配置文件

配置文件版本：2.0.0

### 重大更新
- 将管理、审计、资源管理和消息系统调整为始终启用的基础系统，系统级启停字段不再生效，删除相关运行时开关；移除 `allowAppAuthorization` 配置项，应用授权功能调整为始终启用；并要求配置至少 32 个字符的 SCOW API token。`scow-cli init` 现在会自动生成安全随机的 API token，并在覆盖初始化时安全保留符合长度要求的已有 token。 ([9bc9514f](https://github.com/PKUHPC/private-scow/commit/9bc9514f69bd6e1b160f7bf1afb93445f58cc855))
- 将 scowd 调整为所有集群必需的基础服务，移除集群级启停状态，要求每个集群至少配置一个登录节点，并要求为每个登录节点配置有效的 scowd 端口。 ([9bc9514f](https://github.com/PKUHPC/private-scow/commit/9bc9514f69bd6e1b160f7bf1afb93445f58cc855))
