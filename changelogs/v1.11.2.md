# 适配器接口版本的要求变化

- 新增 scheduler adapter 的本地 proto 定义，覆盖 account、app、config、job、node、user、version 等服务接口。

同时将 generate 脚本改为直接基于仓库内 `./protos` 生成代码，便于与仓库内适配器实现保持同步迭代。
- 删除开源许可声明，统一执行 lint format
